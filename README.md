# AI Website Generator

OpenRouter API use karke simple prompt se professional multi-page website generate karein!

## Features ✨

- **Prompt Enhancement**: Simple idea ko detailed prompt mein convert karta hai
- **Multi-Page Website**: Multiple pages (Home, About, Contact, etc.) generate karta hai
- **Online Images**: Unsplash se automatic images add hoti hain
- **Premium Icons**: Font Awesome icons integrated
- **IDE Integration**: Monaco Editor (VS Code jaisa) built-in
- **Live Preview**: Real-time website preview
- **Code Editor**: HTML, CSS, JS edit kar sakte ho
- **Download**: Saari files download kar sakte ho

## Setup Instructions 🚀

1. **OpenRouter API Key**:
   - https://openrouter.ai/ par jao
   - Account banao aur API key generate karo
   - `script.js` file mein line 2 par apni API key dalo:
   ```javascript
   const OPENROUTER_API_KEY = 'sk-or-v1-YOUR_API_KEY_HERE';
   ```

2. **Run Karo**:
   - Simply `index.html` file ko browser mein open karo
   - Koi server ki zarurat nahi!

## Kaise Use Karein 📝

1. **Step 1**: Apna website idea enter karo
   - Example: "Ek restaurant ka website banao jisme menu, gallery aur contact form ho"

2. **Step 2**: "Prompt Enhance Karein" button click karo
   - AI tumhara prompt enhance karega

3. **Step 3**: "Website Generate Karein" button click karo
   - Complete website generate hogi with multiple pages

4. **Preview & Edit**:
   - Preview tab mein website dekho
   - Code Editor tab mein code edit karo
   - Pages tab mein saare pages dekho

5. **Download**: Download button se saari files download karo

## Technologies Used 💻

- HTML5, CSS3, JavaScript
